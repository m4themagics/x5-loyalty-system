# recsys

Движок решения QuestRank и данные для демо.

Спецификация продукта — в [`docs/project/`](../docs/project/). Формулировка многоцелевой задачи —
раздел 8.4 [описания проекта](../docs/project/project-description.md).

## Что здесь сейчас

- `schema/action.schema.json` — контракт между движком и клиентом. Единственный источник правды по
  полям действия. Совпадает с разделом 8.3 описания проекта и Материалом 6 продуктовых материалов;
  при изменении поля правятся все три.
- `fixtures/` — фиксированные данные для интерфейса, пока движок не готов.

| Файл | Что показывает |
| --- | --- |
| `masha.json` | `personal_finish`, supplier trial на входе, фаза `onboarding` |
| `masha-cycle2.json` | тот же пользователь после успешного цикла: подкрепление снизилось до `digital_unlock`, фаза `confirmation` — это и есть reward fading |
| `masha-completed.json` | визит засчитан, награда выдана, маршрут закрыт и остался в истории |
| `katya.json` | `store_coop` без материальной награды, фаза `persistence` |
| `sergey.json` | `no_action`: платное воздействие не показано |
| `fraud-delayed.json` | `family_relay` в `delayed`, hold по shared device/payment |
| `console-masha.json` | консоль продакта: кандидаты, отсечённые с причиной |
| `console-sergey.json` | консоль для `no_action` — почему платить не стали и сколько сэкономлено |

Каждая фикстура содержит `profile`, `action`, `explanation` и `route_state`. `explanation` — то, что
формулирует LLM из уже выбранного действия; менять в нём условия нельзя.

- `validate_explanation.py` — контракт LLM: объяснение проверяется против уже выбранного действия.
  Ловит выдуманную цену и SKU, изменённый срок, обещание причинного эффекта, снятый fraud hold и
  подменённый `action_id`. Невалидный ответ блокируется, отдаётся детерминированный шаблон.
  Состязательные случаи — в `fixtures/explanations-adversarial.json`.

## Правила

Все числа синтетические. Они не являются экономикой X5 и не являются измеренным эффектом — на
защите называть их можно только параметрами сценария.

Когда заработает генератор, фикстуры перестают редактироваться руками: их печатает движок в тот же
формат.

## Проверка

```bash
python3 validate.py             # схема действия
python3 validate_explanation.py # контракт LLM
```
