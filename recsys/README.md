# recsys

Движок решения QuestRank и данные для демо.

Спецификация продукта — в [`docs/project/`](../docs/project/). Формулировка многоцелевой задачи —
раздел 8.4 [описания проекта](../docs/project/project-description.md).

## Что здесь сейчас

- `schema/action.schema.json` — контракт между движком и клиентом. Единственный источник правды по
  полям действия. Совпадает с разделом 8.3 описания проекта и Материалом 6 продуктовых материалов;
  при изменении поля правятся все три.
- `catalog/campaigns.json` — рекламодатели, кампании, биды, бюджеты, флайты, частотные лимиты и
  креативы. Сгенерирован LLM по brand brief, проверен критиком.
- `fixtures/` — фиксированные решения для интерфейса, пока аллокатор не готов.

| Файл | Что показывает |
| --- | --- |
| `masha.json` | `sponsored` personal_finish, supplier trial 18 ₽, фаза `onboarding` |
| `masha-cycle2.json` | тот же пользователь, подкрепление снизилось до `digital_unlock` — reward fading |
| `katya.json` | `sponsored` store_coop без материальной награды: дешёвая кампания выиграла по качеству и пейсингу |
| `sergey.json` | `no_action`: кампания готова платить 32 ₽, но прирост ниже порога инкрементальности |
| `pacing-exhausted.json` | у кампании с бидом 36 ₽ исчерпан пейсинг, выигрывает следующая релевантная |
| `fraud-delayed.json` | `family_relay` в `delayed`; списание с бюджета рекламодателя тоже придержано |
| `console-sergey.json` | консоль аллокации: кандидаты, биды, вердикты, отклонение по порогу |
| `creatives-adversarial.json` | семь попыток креатива выйти за контракт |

Каждая фикстура содержит `profile`, `decision`, `creative_copy` и `route_state`.

- `validate.py` — решения против схемы.
- `validate_explanation.py` — креатив против выбранного решения: цена, выдуманный SKU, изменённый
  срок, обещание эффекта, снятый hold, спрятанная пометка о спонсорстве.
- `PLAN.md` — план работ по зоне.

## Правила

Все числа синтетические. Они не являются экономикой X5 и не являются измеренным эффектом — на
защите называть их можно только параметрами сценария.

Когда заработает генератор, фикстуры перестают редактироваться руками: их печатает движок в тот же
формат.

## Проверка

```bash
python3 validate.py             # схема действия
python3 validate_explanation.py # контракт LLM
```
