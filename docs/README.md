# Документация

**Актуальная концепция: локальная приёмка от 06.09.2026.** X5 Чекпоинт сохраняет игру коллег: коробка → цифровой предмет → инвентарь → четыре предмета → собственная скидка. Локально подключены персональный челлендж, Qwen/fallback-карточка, тестовый чек, обещанный предмет, право на первый физический SKU, резерв, игровые расчёты и локальный обмен дубликатами. Ads, обучаемые модели, реальная выдача и промышленный антифрод остаются следующими шагами.

- **[`project/`](project/)** — первоисточник кейса, актуальные продуктовые решения, план и речь.
- **Инженерные документы ниже** — устройство репозитория и его инфраструктуры. Активные возможности определяет [`CHECKLIST.md`](../CHECKLIST.md); часть кода унаследована от шаблона и не задействована в игровом демо.

Два Markdown-файла названы финальными материалами; содержание актуализируется вместе с каноническими документами. По решению пользователя финальные материалы хранятся только в `docs/presentation/`; копии на рабочем столе не восстанавливаются. При следующем обновлении сверяются продуктовые факты и границы готовности. Это краткие материалы для сдачи, а не полные экспорты: каталог, схемы и подробный план остаются в `project/`.

### Устаревшие требования

Актуальные материалы для кейсодателя — два Markdown-файла выше. Старые требования убрать коробку, выбирать одну из трёх альтернативных механик или обязательно применять reward fading не определяют текущий продукт.
