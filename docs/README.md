# Документация

**Актуальная концепция: финализация от 05.09.2026.** X5 Чекпоинт сохраняет игру коллег: коробка → цифровой предмет → инвентарь → четыре предмета → собственная скидка. Персональный челлендж, первая физическая награда, обмен, RecSys/Ads и антифрод описаны как следующие шаги; наличие документа не означает работающую интеграцию.

- **[`project/`](project/)** — первоисточник кейса, актуальные продуктовые решения, план и речь.
- **Инженерные документы ниже** — устройство репозитория и его инфраструктуры. Активные возможности определяет [`CHECKLIST.md`](../CHECKLIST.md); часть кода унаследована от шаблона и не задействована в игровом демо.

Решение и статус реализации проверяются по разным источникам: кейс задаёт требования, описание проекта — согласованную концепцию, текущий код и результаты проверок — готовность. Имена файлов канонических документов сохраняются; история изменений находится в git.

### Исторические материалы и исключения из текущей работы

[Презентация `deck.pptx`](project/deck.pptx) и материалы в `docs/presentation/` содержат прежние версии решения. Они не служат источником актуальной концепции. Все презентационные файлы, включая PPTX и старые материалы v4/v5, исключены пользователем из этой работы и не синхронизируются автоматически с документацией.

Старые требования убрать коробку, выбирать одну из трёх альтернативных механик или обязательно применять reward fading не определяют текущий продукт.
