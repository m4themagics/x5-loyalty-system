# Пул предметов профиля

Предметы выпадают из коробки и используются в четырёх слотах создания скидки. Их образ сразу показывает пользователю, на какую товарную категорию предмет влияет.

![Все 24 предмета, сгруппированные по редкости](item-pool-preview.webp)

## Редкости

- **Обычный:** базовые предметы для одной понятной категории.
- **Эпический:** более заметный фиолетово-синий предмет для широкой или составной категории.
- **Легендарный:** золотой предмет для сильной тематической подборки или нескольких связанных категорий.

## Создание скидки

Для создания скидки нужно заполнить четыре ячейки. Каждый выбранный предмет расходуется в количестве одной копии. Перенос работает мышью и пальцем; для точного управления на мобильном можно последовательно нажать на предмет и на ячейку.

Редкость определяет силу предмета: обычный даёт 1 очко, эпический — 2, легендарный — 3. Суммарная сила четырёх предметов превращается в базовую скидку:

| Сила набора | Базовая скидка |
| ---: | ---: |
| 4–5 | 5% |
| 6–7 | 7% |
| 8–9 | 10% |
| 10–11 | 13% |
| 12 | 15% |

Три разных предмета из одного тематического рецепта дают ещё 2 процентных пункта, четыре — 3. Максимальная скидка ограничена 18%. Повторы допустимы, но считаются одним совпадением, поэтому побуждают пользователя искать разнообразные предметы.

| Рецепт | Связанные категории |
| --- | --- |
| Доброе утро | Завтраки, выпечка и горячие напитки |
| Свежий выбор | Овощи, фрукты и полезные продукты |
| Вечер без готовки | Снеки, напитки и готовая еда |
| Азиатский ужин | Рыба, рис, лапша и азиатские соусы |
| Ужин шефа | Мясо, свежие продукты и кулинария |
| Сладкая пауза | Десерты, кофе и всё для выпечки |
| Домашний запас | Бакалея, заморозка и продукты долгого хранения |

Интерфейс подсказывает ближайший рецепт и показывает подходящие предметы. Если ни один рецепт не собран, пользователь всё равно получает скидку на категорию самого редкого предмета, но без тематического бонуса. Редкость готовой скидки зависит от суммарной силы: обычная до 6, эпическая от 7 до 9, легендарная от 10 до 12.

Нажатие на предмет в инвентаре открывает его игровую карточку. Текст описывает знакомую ситуацию покупки, блюдо или способ использования, но не называет точную категорию будущей скидки. Так пользователь может догадаться о сочетании сам, а затем выбрать предмет для установки в ячейку.
