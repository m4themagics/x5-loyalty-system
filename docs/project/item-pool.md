# Пул предметов профиля

Предметы выпадают из коробки и используются в четырёх слотах создания скидки. Их образ сразу показывает пользователю, на какую товарную категорию предмет влияет.

![Все 24 предмета, сгруппированные по редкости](item-pool-preview.webp)

## Редкости

- **Обычный:** базовые предметы для одной понятной категории.
- **Эпический:** более заметный фиолетово-синий предмет для широкой или составной категории.
- **Легендарный:** золотой предмет для сильной тематической подборки или нескольких связанных категорий.
