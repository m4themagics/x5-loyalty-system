# Локальный PoC: проверки и незакрытые задачи

Срез аудита от 05.09.2026 для реализации, сохранённой в коммитах `d7609f0`, `24bba8b` и `9cd2bfd`. Команды выполняются из корня репозитория. Этот документ фиксирует техническую приёмку; описание продукта и запуск находятся в [README](../../README.md).

## Подтверждённые проверки

В локальном аудите **05.09.2026** прошли 47 Python-тестов, 35 тестов контракта и состояния, 5 браузерных сценариев персонального пути, проверки типов и три прежних валидатора RecSys. Это подтверждает проверенные сценарии, но не закрывает найденные ошибки.

Повторить основные проверки:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s recsys/engine/tests -t .
bun test packages/contracts/src/demo-poc.test.ts webapp/tests/demo-state.test.ts webapp/tests/demo-progress.test.ts
bun --bun run --cwd webapp e2e:demo -- personal-challenge.spec.ts
```

Для браузерных тестов нужен установленный Chromium Playwright. При его отсутствии: `bun --bun run --cwd webapp e2e:install`. Остальные проверки описаны в [руководстве по тестированию](../TESTING.md) и [RecSys README](../../recsys/README.md).

## Незакрытые задачи

- **Чеки и награды:** закрыть приём покупок до выдачи задания, будущих чеков и строк с нулевой оплатой; довести сохранение обещаний и выбор копий предметов.
- **Экономика:** исправить переходы резервов при выдаче предмета, крафте и погашении. Целевое правило — 2,50 ₽ на копию, максимум купона 10 ₽ и отдельный резерв товара; текущий учёт ещё не соблюдает его полностью.
- **LLM:** усилить проверку количества, категории, даты и физической награды; исправить обработку сетевого таймаута.
- **Прогресс и оценка:** завершить реферальное начисление и окно рейтинга в 28 дней; связать симуляцию с движком и усилить независимость fraud-выборки.

Результат 40/40 относится к черновой агентской разметке. Симуляция пока не проверяет реализованную политику; прохождения реальных людей не проведены. Прибыльность, рост покупок и формирование привычки не подтверждены.

Обмен дубликатами, повторные товарные цели, полный Ads-аукцион, обучение моделей и серверный учёт остаются следующим этапом. Алкоголь, табак и никотин исключены из PoC.


## Особенности текущего демо

- Переключение синтетического профиля сбрасывает его персональный прогресс; перезагрузка страницы сохраняет текущий снимок.
- Персональный сценарий использует общую формулу крафта, но собственную панель выбора и окно награды. Исходная коробка с жестом встряхивания остаётся отдельной песочницей.
- Право на физический товар — запись в браузере. Серверный реестр, выдача на кассе и реальные покупательские данные не подключены.
- Адаптер YandexGPT доступен в коде, но живой вызов не проверен. Без ключа используется шаблон.
- Продуктовая спецификация и материалы защиты пока не полностью отражают новую интеграцию; их статусы требуют отдельной синхронизации.
