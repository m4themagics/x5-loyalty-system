# X5 Loyalty System

Мобильное веб-демо игровой программы лояльности для «Пятёрочки».

Проект превращает обычные покупки в понятный игровой прогресс: после покупки пользователь получает возможность крутить колесо призов, выполняет персональные задания и зарабатывает голоса. Голоса можно направлять на улучшения конкретного магазина — например, расширение ассортимента, дополнительные кассы самообслуживания или повышение чистоты.

## Основная идея

- колесо призов после покупки с картой лояльности;
- качество возможных призов зависит от суммы чека;
- дорожка уровней с видимыми наградами;
- персональные задания на основе истории покупок;
- голоса за улучшения выбранного магазина;
- привилегии постоянных покупателей, экономящие время;
- персональные предложения и рекомендации по прошлым покупкам.

## Что реализовано

- адаптивная копия главного экрана приложения «Пятёрочки»;
- интерфейс для мобильной ширины 360–430 px;
- основной дизайн рассчитан на экран 390×844 px;
- нижняя навигация;
- переход между главной страницей и пустым разделом профиля;
- демонстрационные данные без подключения backend.

Кнопки, кроме переходов «Главная» и «Профиль», пока выполняют только визуальную функцию.

## Технологии

- React 19;
- TypeScript;
- Vite;
- CSS и Tailwind CSS;
- Bun.

## Локальный запуск

Требуется Bun 1.3.14.

```bash
bun install
bun run dev:webapp
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```

## Проверка проекта

```bash
bun run typecheck:webapp
bun run lint
bun run test:webapp
bun run build:webapp
```

## Статус

Проект находится на стадии интерактивного прототипа для хакатона. Реальные покупки, аккаунты, платежи и внешние интеграции пока не подключены.
